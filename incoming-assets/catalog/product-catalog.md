# Caramel Showroom — Product Catalogue Intake Template

Use this document to prepare your genuine product records and image filenames before importing them into the Caramel showroom.

---

## Intake Instructions

1. **One Entry Per Real Product**: Fill out the fields below for each genuine piece in your inventory.
2. **Exact Filenames**: Write the exact filenames of your photographs placed in `incoming-assets/products/<product-slug>/`. Do not guess or leave filenames blank.
3. **Genuine Color Variants**: If a piece is available in multiple colors, provide separate photographs for each color. Selecting a color swatch switches the photo to that specific color.
4. **Single-Edition Pieces**: If a product has only one color or no variants, leave the Variant 2 block blank. The showroom will automatically display the piece cleanly without fake color selectors.
5. **Accurate Prices & Genuine Discounts**:
   - `Current price (EGP)`: Required. Enter numeric amount in Egyptian Pounds (e.g., `3200`).
   - `Original price (EGP)`: Optional. Enter ONLY if there is a genuine discount, and it MUST be strictly greater than Current price (e.g., Current: `3200`, Original: `3800` = 16% OFF). Leave blank if there is no discount.
6. **Bilingual Text**: Provide Arabic and English names. If an English description is not ready, Arabic is sufficient, or vice-versa.
