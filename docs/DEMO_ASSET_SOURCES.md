## 3. Policy on Demo Visuals

1. **Clear Demo Notice:** All preview demo assets are presented under active `catalogMode: "demo"` with bilingual preview notice banners.
2. **No Fictional Endorsement:** Demo visuals are never presented as authentic stock or genuine owner inventory.
3. **Seamless Replacement:** When the brand owner provides approved studio campaign photography, these files can be directly replaced in `public/images/` without altering component code.
